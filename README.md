# health-information
Health Information for Alexander Ferrari Miller

“What do I know about my health?”

This repository contains the reference information about my health: diagnoses, medications, providers, medical history, laboratory results, and other information that changes relatively infrequently.

## Daily Health Log Standard

Each daily health log follows a consistent structure.

### Morning Medications

Record each scheduled morning medication with a ✓ when taken. Add brief notes only when they are clinically or operationally significant, such as:

- Last tablet taken.

- Refill ordered.

- Medication unavailable.

- Dose changed.

- Medication held on physician's instructions.

### Measurements

Record measurements in the following order:

- Blood Pressure

- Pulse

- Oxygen Saturation

- Pulse (Oximeter)

- Temperature

- Weight

### Notes

Use this section only for unusual events, symptoms, physician instructions, medication changes, appointments, or other observations that may be important when reviewing the log later.
